CamCraft — Advanced Camera App

This project is a recruitment task for Android Club — VIT Bhopal.
CamCraft is a modern CameraX-based Android application that supports:

📸 Core Features

Front & Back camera switching

Flash modes (On / Off / Auto)

Capture photos using CameraX

Custom save folder support

Gallery of saved images

Preview after capture


⚡ Optional Features (will be added soon)

Crop / Rotate

EXIF details

Self-Timer

Grid Overlay

Light/Dark Theme

GPS tagging

Burst mode


🚧 Status

Currently in development.
Initial repository created — features will be added and updated soon.


---

Tech Stack :

Kotlin

Android Studio (Jetpack Compose / XML)

CameraX

MediaStore / SAF

ViewModel + LiveData
